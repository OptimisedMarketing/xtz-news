# Etherlink Hub — Keyword and Source Notes

**Research date:** 7 September 2026  
**Keyword data source:** DataForSEO live US Google SERP for `etherlink tezos`.

## Relevance decision

The disambiguated query **`etherlink tezos`** returned an entirely ecosystem-relevant first page. The top results were Etherlink documentation and website pages, Tezos/Tezos Commons coverage, the Etherlink X profile, and an Etherlink chain page. The related-search set included Etherlink bridge, explorer, wallet, scan, swap, and “bridge XTZ to Etherlink.” This supports a narrowly scoped **Etherlink on Tezos** reader resource page.

The People Also Ask block also included price-prediction and investment-sentiment questions. These are excluded from the hub because XTZ.News will not present price forecasts or investment recommendations as educational content.

## Hub constraints

The hub will aggregate only real XTZ.News posts tagged `etherlink`. It will link to official Etherlink documentation, official bridge documentation, and the official explorer without copying contract addresses or asking users to move funds. Its bridge explanation will direct readers to official documentation and include a clear timing caution.
