# Direct Anthropic Translation Cost Source

Anthropic’s Claude Haiku 4.5 product page states that direct Claude Platform pricing starts at **$1 per million input tokens** and **$5 per million output tokens**. The page also describes up to 50% savings through batch processing, which is not used by the current real-time signed cloud worker.[1]
