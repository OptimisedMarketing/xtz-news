# TezOracle Source Notes

## Announcement

Kevin Mehrabi’s supplied X post, dated 31 August 2026, announces work on **TezOracle** to restore a Tezos ecosystem price feed for Layer 1 and the full Tezos X roadmap. The post describes it as secure, Tezos-native, and independent oracle infrastructure, naming lending, synthetics, perpetuals, prediction markets, commerce, and other applications as potential uses.[1]

## Official site

TezOracle describes itself as Tezos-native oracle infrastructure across Tezos X from Layer 1 to Layer 2. Its stated design combines independent market observations, signer attestations, and oracle consensus to authorise price updates. The site is explicit that the project is **in development**: its architecture and security specification are defined, while implementation, testnet operation, shadow publication, independent review, and release gating remain future stages.[2]

The site says TezOracle will publish destination-bound updates to local Michelson oracle contracts on Layer 1 and the Tezos X execution layer. It frames Native Atomic Composability as the mechanism within Layer 2 that lets TezOracle price information reach EVM applications and compatible EVM oracle readings return as further validation evidence.[2]

## Editorial framing

The article should frame TezOracle as a project **being developed**, not a deployed production price feed. The central news is the intention to restore Tezos-native price-feed infrastructure and the proposed architecture’s L1-to-L2 design. Any security or availability outcomes must be attributed as planned design, not presented as current production capability.
