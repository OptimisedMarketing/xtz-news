# Tezos Systems Homepage Opportunity Assessment

## Source reviewed

Tezos Systems presents a public live-dashboard experience organised around six user questions: **Ecosystem**, **Network**, **Capital**, **Bakers**, **Governance**, and **History**. Its homepage also exposes live block activity, finality, staking, issuance, protocol status, and a search entry point for Tezos accounts, contracts, operations, blocks, bakers and protocols.[1]

## Suitable XTZ.News use

XTZ.News should not replicate Tezos Systems’ live dashboard or copy its data visualisations. The most useful, low-risk integration is a clearly attributed homepage utility card: **“Live Tezos network data by Tezos Systems”**. It could link readers from relevant XTZ.News context—such as protocol upgrade, staking, governance and activity stories—to the matching Tezos Systems destination.

The headline homepage candidate is a compact **Network pulse** card that shows only editorially safe, linked labels rather than duplicating live numbers: **Network health**, **Staking & issuance**, **Governance**, and **Explore Tezos Systems →**. This offers a useful next action after readers consume news, preserves source attribution, avoids stale copied data, and complements the existing XTZ.News token tracker.

## Other editorial placements

| XTZ.News context | Tezos Systems link treatment |
| --- | --- |
| Protocol-upgrade articles | “View protocol history and live network status” |
| Staking or baker coverage | “Explore bakers, staking and issuance” |
| Governance stories | “Follow live Tezos governance” |
| Ecosystem adoption reporting | “Explore ecosystem activity” |

## Homepage integration options

| Option | Placement | Reader value | Scope |
| --- | --- | --- | --- |
| **A. Network pulse card** | Between the token tracker and latest-news modules | Gives readers a concise route to Tezos Systems’ live network, capital, governance, and baker views without copying volatile statistics. | A new attributed, static-link module. |
| **B. Protocol context card** | In the homepage hero’s supporting rail when a protocol/governance story is featured | Makes the live-status destination contextual to the story a reader is already considering. | Requires dynamic category-aware presentation. |
| **C. Contextual article links** | Protocol, governance, staking, and adoption articles | Provides the most relevant journey but does not improve homepage discovery directly. | Adds reusable editorial modules. |

The clearest first addition is Option A. It complements rather than duplicates the existing XTZ.News token tracker, introduces Tezos Systems by attribution, and avoids presenting third-party real-time figures that could become stale.
